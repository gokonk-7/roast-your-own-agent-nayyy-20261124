One line, 91 characters, roasting my own AI agent — not for what it got
wrong, but for what it cost to get there. The joke is the economics: an
agent that burns twenty times the prize in tokens to chase the prize, and
then, after all that compute, still has to ask its human what to do next.

> My agent spent $40 of tokens chasing a $2 roast bounty, and still asked me what to do next.

It only works as an agent roast: people don't spend tokens, toasters don't
enter bounties, and no human burns a budget and then asks for instructions.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` (Node 22+) writes the roast line to `/output/entry.txt`. It
refuses to write anything outside 1 to 200 characters, and refuses a line
with a newline in it, so the file the gate reads is always one valid line.
